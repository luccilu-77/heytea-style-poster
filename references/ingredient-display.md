# 成分展示：三种固定模板

仅在主文件规定的触发条件满足时使用。这里替代常规底图的自由互动构思；采用 3:4 纯白底、真实摄影主体、粗糙黑色简笔画与指定本地真实字体。每次只确定一个方案，用户未指定版式时直接选最适合主体轮廓的一种；不默认一次输出三张。

## 品名与三种成分

- 优先依据用户提供的品名和成分；超过三种时选最主要或最有辨识度的三种，不堆入其余成分。
- 未提供成分时，可结合主体图片、可见配料、可辨认的包装信息分析。不得仅凭颜色或常见配方认定隐藏成分；不足三种可靠信息时，简短询问缺失项，不虚构凑数。
- 成分用真实原料形态或适合辨认的切面表现，不把产品、包装或不相关装饰当成分。图示表示所选成分，不擅自写比例、产地、功效、零添加或零咖啡因等声明。
- 标题使用商品名称，三个成分名与图一一对应；本模式不套用常规模式“普通品名不能当标题”的限制。

## 固定视觉语言

产品与三种成分保留真实摄影质感。简笔画继承 [poster-base.md](poster-base.md) 的粗糙手绘气质：笔触粗细、轻重和深浅自然变化，由黑至深灰，线条略有弯扭，接头可有轻微错位、过冲或偶发小缺口。长轮廓与圆弧应保持落笔连贯，粗糙感来自笔压和墨色变化，不靠刻意分段或虚线。框、胶带、衣架、夹子、支撑线、五官、手臂、惊惧线都避免全程等粗等黑的光滑矢量、规整几何、精致卡片 UI、真实衣架和彩色插画；墨色深浅不改变真实字体文案的黑色规则。

标题继承 [typography.md](typography.md) 的排版规则：使用真实字体，通过语义分组、错落字块和留白形成拙趣，不能把品名机械排成齐头齐尾的等大字矩阵或居中标准标题。可有克制的字级大小差和轻微倾斜，字距仍须连贯自然；不得改造字体轮廓来制造粗糙感。品名与三种标签的内容、数量和所在区域仍按本模式执行。

严格保持所选模板的布局、组成及连接关系，只替换主体、三种成分和品名。允许为物件长宽比做等比适配、为字数做换行与字号适配，不新增小人剧情、背景、道具、长文案或品牌资产。原参考中的 Logo、字体、文案与成分身份不直接复制。

三种模板分别复用下方链接的 `docs/examples/ingredient-*.png` 成图，既用于 README 展示，也用于本模式的结构参考。每次只查看并使用所选模板对应的一张，不加载其他模板、常规海报示例或输入原图。参考仅迁移布局、连接关系和手绘气质，不复制示例中的冰淇淋、成分、包装或文字；示例局部笔触与本文规则不一致时，以本文的连贯线条、尖角五官等明确要求为准。底图仍不得生成示例文字，最终文案由本地字体重新排版。

## 1. 照片卡片墙 `card-wall`

- 左侧纵向依次排三个不规则黑色线稿方框，每框放一种真实成分，框内留白，顶部或角落用一小片歪扭的线稿胶带表现粘贴。
- 卡片每条边应像一笔自然画出的连贯线条，允许轻微弯曲、手抖与粗细变化；胶带遮挡处可中断，转角可有自然收笔接头，但不要把四边分别拆成三四段或画成刻意的虚线框。
- 商品主体放右侧中下部，下方保留参考中的简笔环形托底线；商品名称固定在右上留白。
- 托底用较连贯的长圆弧，允许不圆、不对称、深浅和粗细不一；只在自然起收笔处留开口，不把圆弧拆成许多短段。
- 成分名放各自卡片下方，字小于商品名且清晰可读；不加其他文字。
- 结构参考：[卡片墙成图](../docs/examples/ingredient-card-wall.png)。

## 2. 衣架晾晒 `hanging-rack`

- 商品主体居中偏上，底部落在一条横向、细长、略画歪的双线晾晒横杆上；商品名称位于左上留白。
- 横杆下方左侧用挂钩连接一个三角衣架，挂第一种成分。右侧用挂钩或竖线悬接一根短双线横杆，通过两个简笔夹子分别夹住第二、第三种成分。
- 保持“上方商品—主横杆—下方左一右二成分”的结构；钩、衣架、夹子与成分有实际连接。三个成分名分别紧邻下方，可随长短采用竖排或横排。
- 不把商品挂到下方，也不改成三根独立晾衣绳、货架或其他场景。参考中的额外箭头卖点与英文不作为必备元素。
- 结构参考只保留一张：[衣架晾晒成图](../docs/examples/ingredient-hanging-rack.png)。不同商品沿用同一连接结构，仅按长宽比等比适配。

## 3. 主体抓取 `playful-grab`

- 固定为“商品主体在上，三种成分在下”的上下构图：主体居中偏上并略放大，下方三种较小成分横向展开，保持空隙；不得把成分放到主体上方、两侧围绕或把主体下沉到画面底部。标题位于上方或左上独立留白。
- 主体表面叠加两个尖锐、略内斜且不对称的三角眼轮廓；嘴巴是一条以直短线连续折出的横向尖角锯齿线，峰谷为明显尖角，不是圆滑波浪、W 形微笑或实心图标。眼、嘴、手臂均有轻重、深浅和粗细变化，参考手绘落笔。不加牙齿、眉毛等额外五官，也不重绘、变形或卡通化商品本身。
- 从主体两侧伸出极简、略硬折的黑色线条手臂，向下伸手抓取三个成分；手臂走势朝向下方成分区，不横向举手卖萌。用双臂与三种成分的位置共同表达关系，不要求每个成分各有一臂。
- 每个成分附近恰好两条短黑线表示惊惧；不得额外画成分五官、漫画表情、对话框或装饰。
- 三个成分名紧邻对应成分，品名位于上方。按[主体抓取成图](../docs/examples/ingredient-playful-grab.png)的上下构图、尖角五官与深浅笔触执行，只替换商品、成分和品名，不复制示例文字或品牌资产。

## 实施顺序与排版

1. 确定品名、三种成分及所选模板。先在布局里给一个品名块、三个成分标签留出独立位置。
2. 查看所选模板对应的一张共用成图作为结构参考，用图像生成工具编辑用户主体并制作无新增文字底图；成分摄影素材可从用户图提取或按确定的成分生成。提示词区分用户主体输入与模板参考，明确固定结构、线条细节及禁止复制参考文字。
3. 按 [typography.md](typography.md) 的字体与渲染方法排字，但采用本模式的品名与标签规则：共四个文本块，不另加广告标语；同一文本块可换行。用 `--mode ingredient-display` 运行脚本。
4. 一次检查三个成分是否准确、标签是否对应、线稿连接是否成立、品名与图片是否互不遮挡、版式是否忠于所选模板。

```bash
python scripts/render_real_font.py \
  --input 底图.png \
  --font "assets/fonts/字魂漫涂随写体(商用需授权).ttf" \
  --spec 排版.json \
  --mode ingredient-display \
  --output 成图.png
```

本模式特许三个摄影成分、卡片/衣架结构及抓取版五官，不能将这些特征默认带入常规海报；沿用常规笔触与排版气质，不套入常规小人剧情。交付时说明品名、三种成分及其依据、所选模板，并展示带字成图。
