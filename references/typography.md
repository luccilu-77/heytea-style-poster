# 真实字体标题排版

所有新增文字使用 `assets/fonts/字魂漫涂随写体(商用需授权).ttf` 确定性渲染。

## 文案

- 文案从主体特征、食用体验或生活场景出发，优先写轻松、有网感和记忆点的短句，可用自然的谐音、熟语转化、季节感或生活情绪；不强行呼应小人故事，也不强凑梗。
- 普通产品名不直接作为标题；名称本身有特色、节奏或画面感时可以保留。直接确定一个文案方案即可。
- 使用自然、完整的人话，避免为凑字数或版式生硬拼接词语。
- 使用 1–3 处文案，每处不超过 10 个汉字；通常一句主标题即可，其他文字只在有信息价值且空间充足时添加。

## 排版

- 标题优先放在上方或侧面的连续留白区，成为主体之外最醒目的视觉信号，同时与主体保持明显间隔。
- 根据文案长度和留白选择横排、竖排、分行或主副分组，不强制固定模板。
- 多列竖排按从左到右的列序阅读。
- 使用字体自然字形和稳定字距；松弛感来自文字块的尺度、位置与留白，不依赖逐字随机疏密或明显旋转。
- 主标题字号应足够醒目但不贴边、不遮挡主体、小人、动作线和关键纹理。
- 所有文案统一使用纯黑色 `#111111`；不得非等比拉伸或修改字形轮廓。

## 渲染

将排版参数保存为 UTF-8 JSON：

```json
{
  "blocks": [
    {
      "text": "一壶春意",
      "x": 0.12,
      "y": 0.10,
      "font_size": 0.09,
      "color": "#111111",
      "tracking": 0.004
    }
  ]
}
```

每个 block 至少包含 `text`、`x`、`y`、`font_size`；可选字段为 `color`、`opacity`、`tracking`、`char_rotations`、`char_y_offsets` 和 `line_spacing`。

需要准确复现错落字块时，可用 `char_positions` 为每个非换行字符指定 `x`、`y`，并可附 `font_size`、`rotation`；条目数须与字数相同。位置应按语义与实际字形安排，保持连续视觉字距，不随机抖动。

```bash
python scripts/render_real_font.py \
  --input 底图.png \
  --font "assets/fonts/字魂漫涂随写体(商用需授权).ttf" \
  --spec 排版.json \
  --output 成图.png
```

验收时确认文案无错字、主次清楚、字距自然、方向正确、没有贴边或遮挡。若失败，只调整排版 JSON；底图本身没有安全区时才重新生成。
